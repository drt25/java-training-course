Java 8 stream
A stream is not a new kind of list. It is a way to process the list you already have.

Stream API

A pipeline over a collection.

Use it on a List or a Set when you want to select, change, print, or collect values.

List<Integer> numbers =
    Arrays.asList(10, 20, 30, 40, 50);
A stream does not store data. The original collection holds the values. The stream processes them.

stream()

Start processing the list.

numbers.stream() means: I want to process the elements of this list.

List<Integer> numbers =
    Arrays.asList(10, 20, 30, 40);

numbers.stream();

numbers.stream()
       .forEach(n -> System.out.println(n));

Creates a stream

From the collection you already have. Nothing is copied into a new store.

Almost never alone

You connect stream() to filter, map, forEach, or collect.

Then an action

Print, select, change, or store. The chain is the pipeline.

filter()

Keep only the values that pass a test.

n -> n > 20 means: take each number n. Keep it if it is greater than 20.

List<Integer> numbers =
    Arrays.asList(10, 20, 30, 40, 50);

numbers.stream()
       .filter(n -> n > 20)
       .forEach(n -> System.out.println(n));
30 40 50
filter() selects elements based on a condition.
10drop
20drop
30keep
40keep
50keep

20 is not greater than 20, so it drops too.

map()

Change each element into another value.

map() does not drop items. Every item goes in. A new value comes out.

List<Integer> numbers =
    Arrays.asList(1, 2, 3, 4);

numbers.stream()
       .map(n -> n * 2)
       .forEach(n -> System.out.println(n));
1→ 2
2→ 4
3→ 6
4→ 8
List<String> names =
    Arrays.asList("ram", "sita", "hari");

names.stream()
     .map(name -> name.toUpperCase())
     .forEach(name -> System.out.println(name));
ram→ RAM
sita→ SITA
hari→ HARI
map() transforms each element into another value.

collect()

Store the processed values in a new list.

Use collect when you need the result back as a collection. The original list stays as it was.

List<Integer> numbers =
    Arrays.asList(10, 20, 30, 40, 50);

List<Integer> result =
    numbers.stream()
           .filter(n -> n > 20)
           .collect(Collectors.toList());
result → [30, 40, 50]
Original[10, 20, 30, 40, 50]
↓ stream()
filter > 20[30, 40, 50]
↓ collect()
New List[30, 40, 50]
collect() collects the processed stream elements into a collection.

Date-Time API

Dates and times live in java.time.

Java 8 added a new Date-Time API. For beginners, three classes cover most work.

Date only

LocalDate

Year + month + day. 2026-09-19

Time only

LocalTime

Hour + minute + second. 10:30

Both

LocalDateTime

Date and time together. 2026-09-19 10:30

Pick the class that matches what you need. A birthday is a date. A class start is a time. A login is both.

LocalDate

A date. No clock.

LocalDate is year + month + day. Use it for today, a birthday, or a due date.

LocalDate today = LocalDate.now();
System.out.println(today);

LocalDate date =
    LocalDate.of(2026, 9, 19);
LocalDate
2026-09-19

Year + Month + Day

now()

Today’s date from the computer.

of(year, month, day)

A date you choose. Month is 1 to 12.

DateTimeFormatter

Print the date in the shape you want.

Default looks like 2026-09-19. Nepal class work often wants 19-09-2026.

LocalDate today = LocalDate.now();

DateTimeFormatter formatter =
    DateTimeFormatter.ofPattern("dd-MM-yyyy");

String formattedDate =
    today.format(formatter);
19-09-2026
DateTimeFormatter formats dates and times into a desired pattern.
ddday
MMmonth
yyyyyear
HHhour
mmminute
sssecond

dd-MM-yyyy means day-month-year. MM is month. mm is minute.

plus adds. minus subtracts. Assign the result.

Dates do not change in place. plusDays returns a new date. Store it.

Compare

Earlier, later, or the same.

10 September comes before 20 September. Ask the date. Do not subtract by hand.

LocalDate date1 =
    LocalDate.of(2026, 9, 10);
LocalDate date2 =
    LocalDate.of(2026, 9, 20);

date1.isBefore(date2);
date1.isAfter(date2);
date1.isEqual(date2);
isBefore() Is it earlier? true
isAfter() Is it later? false
isEqual() Are they the same? false
