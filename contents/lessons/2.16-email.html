An App Password is separate from the normal Gmail password. Leave it out of Git and out of the class chat. If Google hides App Passwords for that account, use another SMTP host the account is allowed to use. Help: Google App Passwords.

pom.xml

One starter gives Spring the mail library.

pom.xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-mail</artifactId>
</dependency>

Spring Boot then creates a JavaMailSender when the mail settings are present. Mail guide: Spring Boot email.

application.properties

Point Spring at Gmail. Keep the password outside the file.

application.properties
spring.mail.host=smtp.gmail.com
spring.mail.port=587

spring.mail.username=${MAIL_USERNAME}
spring.mail.password=${MAIL_PASSWORD}

spring.mail.properties.mail.smtp.auth=true
spring.mail.properties.mail.smtp.starttls.enable=true

What each line does

Port 587 talks to Gmail with a login and TLS.

PropertyPurpose
spring.mail.hostGmail's SMTP server, smtp.gmail.com.
spring.mail.portSMTP port 587.
spring.mail.usernameThe Gmail address.
spring.mail.passwordThe App Password.
mail.smtp.authTurns on SMTP login.
starttls.enableTurns on TLS encryption.

Before mvn spring-boot:run, export MAIL_USERNAME and MAIL_PASSWORD in that terminal. A real password never goes in the committed properties file.

JavaMailSender arrives through the constructor, the same way a repository does. Spring builds it from the mail properties.

Try it

A POST starts the send.

EmailController
@RestController
@RequestMapping("/api/email")
public class EmailController {

    private final EmailService emailService;

    public EmailController(EmailService emailService) {
        this.emailService = emailService;
    }

    @PostMapping("/send")
    public String sendEmail(@RequestBody EmailRequest request) {
        emailService.sendWelcome(request.getName(), request.getEmail());
        return "Email sent successfully!";
    }
}

That sentence comes back when send finishes. A failure throws, so Postman shows an error instead of the sentence.
