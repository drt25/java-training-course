String

What is a String?

A String is a class, not a primitive like int. It is an object that holds a sequence of characters.

Text in quotes

String name = "Ram"; — name, phone, message.

"12345" is still text

It looks like a number. Inside quotes you cannot add it as an int.

The variable is an arrow

name points at the object. Methods live on the object: name.length().

Pool

The String pool

Two literals with the same letters can share one object. That is safe only because nobody can change those letters.

String pool

a b
↓    ↓
"Java"
Use "Java" for normal text. new String("Java") forces a second object — we use it only to see the pool, not in app code. Sharing is safe because the contents cannot change.

Pool · when

== vs equals

== asks “same object?” equals asks “same letters?” For names and PIN text, always equals.

String a = "Java";
String b = "Java";
String c = new String("Java");

a == b;           // true  — same pooled object
a == c;           // false — new made a second object
a.equals(c);      // true  — same letters
a == b: true a == c: false a.equals(c): true
== is a pool lesson, not a login check. Lab: coding/1.3-string/StringPoolDemo.java

Why Builder exists

Too many + is slow

String result = "";
for (int i = 1; i <= 10000; i++) {
    result = result + i;
}
""
"1"
"12"
"123"
"1234"
…

Each + builds a new String. A few joins are fine. A long loop means many objects. That is why we use StringBuilder.

StringBuilder

StringBuilder can change

String = printed book

Hello

You cannot change the printed word. “Hello Java” needs another printing.

StringBuilder = whiteboard

Hello → Hello Java

You add on the same board. The object itself can change.

StringBuilder builder = new StringBuilder("Hello");
System.out.println(System.identityHashCode(builder));  // demo only — not a String method
builder.append(" Java");
System.out.println(System.identityHashCode(builder));  // same number — same object
System.out.println(builder);                           // Hello Java

Build a report

StringBuffer

StringBuffer is for two writers

Same append as Builder. The extra rule: if two threads write the same buffer, Buffer makes them wait.

StringBuffer buffer = new StringBuffer("Hello");
buffer.append(" Java");
System.out.println(buffer);
Hello Java

Builder

Two threads can write at once. You must lock it yourself.

Buffer

Synchronized methods. One writer waits if needed.

Today’s labs: use StringBuilder. Real threads come in 1.8.
