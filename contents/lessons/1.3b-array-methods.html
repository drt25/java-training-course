Why methods

Method types

Four useful combinations

Ask two questions: does data go in? Does a value come out?

1

No in · no out

void greet() — just print Hello.

2

In · no out

void greet(String name) — print Hello Ram.

3

No in · out

int getAge() — return 25;

4

In · out

int add(int a, int b) — send 10 and 20, get 30.

Parameter vs argument

The hole in the box. The value you put in.

public static void greet(String name) {
    System.out.println("Hello " + name);
}

greet("Ram");
greet("Hari");

Remember

name is the parameter — the placeholder.

"Ram" is the argument — the real value.

Return

void does a job. return gives a value back.

This return is not “leave login” from 1.2. Here it means: send an answer to the caller.

10 and 20 go in

add(10, 20)

The method adds

return a + b;

30 comes out

int result = add(10, 20);

public static int add(int a, int b) {
    return a + b;
}

Overloading

Same name. Different parameters.

Java picks the method by what you pass in. Changing only the return type is not enough. OOP overloading with objects waits in 1.5.

public static int add(int a, int b) {
    return a + b;
}

public static int add(int a, int b, int c) {
    return a + b + c;
}

add(10, 20);        // two ints
add(10, 20, 30);    // three ints

Not allowed

Two methods named add with the same (int, int) — even if one returns int and one returns double.

Remember

Curly braces fill values now. new int[5] makes five rooms. Java puts 0 in each int room until you set them.

Loop

You know for. Today we add for-each.

From 1.2: for (int i = 0; i < marks.length; i++) and marks[i]. When you only need the value, use for-each.

int[] marks = {80, 75, 90, 85};

for (int mark : marks) {
    System.out.println(mark);
}

Read it as

Take each number from marks. Put it in mark. Print. Repeat until the list ends.

java.util.Arrays

Main helpers. Two more names. Then explore.

Array with methods

Send the list in. Or send a list back.

public static void printMarks(int[] marks) {
    for (int mark : marks) {
        System.out.println(mark);
    }
}

printMarks(marks);

public static int[] getNumbers() {
    return new int[]{10, 20, 30, 40};
}

The list is the argument

int[] marks is the parameter. The whole array goes in — you do not pass one number at a time.

Together

Student marks — one small program

main holds the array. It asks printMarks to show each score. It asks calculateTotal for the sum.

int[] marks = {80, 75, 90, 85, 70};
printMarks(marks);
int total = calculateTotal(marks);
System.out.println("Total: " + total);

Flow

main → array → printMarks(marks) → calculateTotal(marks) → total comes back.
