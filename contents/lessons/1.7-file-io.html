File vs stream

File is the paper. A stream is the pen.

File helps us manage the file itself. It does not read or write the content. Streams move data in or out.

File

The paper on disk. Name it. Create it. Check it. Delete it.

Stream

The pen. Write text into the file. Read text out of the file.

Path: File → Write → Read → Store Java types → Tokens → Jump → Small project

File class

Manage the file. Do not write the story yet.

exists(), getName(), createNewFile(), delete(). If create fails, catch IOException.

File file = new File("student.txt");

System.out.println(file.exists());
System.out.println(file.getName());

if (file.createNewFile()) {
    System.out.println("File created.");
} else {
    System.out.println("File already exists.");
}

file.delete() removes it.

Write text

FileWriter puts text into the file

Open. Write. Close. Always close when you finish.

FileWriter writer = new FileWriter("student.txt");

writer.write("John");
writer.write("\nSarah");

writer.close();
John Sarah

Remember

FileWriter writes text. Lab: WriteNames.java

Read text

FileReader brings text back into the program

Read one character. -1 means the file is finished.

FileReader reader = new FileReader("student.txt");

int data;
while ((data = reader.read()) != -1) {
    System.out.print((char) data);
}

reader.close();

Remember

FileWriter → file. FileReader ← file.

Why data streams

FileWriter stores text. Sometimes we want real Java values.

int, double, boolean, String. FileOutputStream only gives the data stream a file to write into.

DataOutputStream output =
        new DataOutputStream(
                new FileOutputStream("student.dat"));

output.writeInt(101);
output.writeUTF("John");
output.writeDouble(85.5);

output.close();

Remember

DataOutputStream writes Java data. Lab: DataWrite.java

Read Java data

Read in the same order you wrote

Write int, then String, then double. Read int, then String, then double.

DataInputStream input =
        new DataInputStream(
                new FileInputStream("student.dat"));

int id = input.readInt();
String name = input.readUTF();
double marks = input.readDouble();

input.close();

Beginner rule

DataOutputStream writes Java data. DataInputStream reads Java data.

Lab: DataRead.java

Tokens

A token is one small piece of text

You already used Scanner for the keyboard. The same Scanner can read a file. next() reads one token.

Scanner scanner = new Scanner(new File("student.txt"));

while (scanner.hasNext()) {
    String token = scanner.next();
    System.out.println(token);
}

scanner.close();
John 25 Kathmandu

Example

John 25 Kathmandu has three tokens: John, 25, Kathmandu.
