Why collections

If arrays store many values, why collections?

An array has a fixed size. That is fine when you already know the count.

String[] months = new String[12];

String[] names = new String[3];
names[0] = "John";
names[1] = "Sarah";
names[2] = "David";
Twelve months never change. An array is a good fit. A student roster can grow next week.

To add a fourth name to a size-3 array, you would make a new array and copy the old data.

Collection

A collection grows as you add and shrinks as you remove.

Use an array when the size is fixed and known. Use a collection when the number of elements can change.

List<String> students = new ArrayList<>();

students.add("John");
students.add("Sarah");
students.add("David");

students.add("Emma");
students.remove("John");

List

A List keeps order. Duplicates are allowed.

You can read an element by its position. Counting starts at 0, same as an array.

List<String> names = new ArrayList<>();

names.add("John");
names.add("Sarah");
names.add("John");

System.out.println(names.get(0));
0John
1Sarah
2John
get(0) prints John. The second John stays. A List does not throw that away.

Use a List for students, products, orders, or messages — when order matters and repeats are fine.

ArrayList

Start with ArrayList.

If you need a List and have no special reason to pick something else, use ArrayList.

List<String> names = new ArrayList<>();

names.add("John");
names.add("Sarah");
names.add("David");

System.out.println(names.get(1));

Index access

get(1) is Sarah. Reading by position is what ArrayList is good at.

Mostly add

You usually append names at the end. That is the common beginner pattern.

General purpose

This is the default List for class work and small apps.

LinkedList

LinkedList is another List. It shines at the ends.

Use it when you often add or remove from the beginning or the end.

LinkedList<String> names = new LinkedList<>();

names.addFirst("John");
names.addLast("Sarah");

names.removeFirst();
names.removeLast();

addFirst / addLast

Put a name at the front or the back in one call.

removeFirst / removeLast

Take a name off either end. A queue-like flow.

Still a List

Order is kept. Duplicates are still allowed.

Set

A Set stores unique values.

A duplicate is not added. Java does not throw an error. add() returns true or false.

Set<String> emails = new HashSet<>();

System.out.println(emails.add("john@gmail.com"));
System.out.println(emails.add("sarah@gmail.com"));
System.out.println(emails.add("john@gmail.com"));
Set<String> emails Unique

Use a Set for usernames, emails, product IDs, tags, or permissions. Lab: SetDemo.java

HashSet

HashSet means unique values. Order is not promised.

Do not expect 101, then 102, then 103 every time you print the set.

Set<Integer> ids = new HashSet<>();

ids.add(101);
ids.add(102);
ids.add(101);
stored101
stored102
ignored101
The second 101 is not stored. HashSet = unique values.

Map

A Map stores a key and a value together.

Think of a dictionary. You ask with a key. You get the matching value.

Map<Integer, String> students = new HashMap<>();

students.put(101, "John");
students.put(102, "Sarah");
students.put(103, "David");

System.out.println(students.get(101));
101→John
102→Sarah
103→David
get(101) prints John.

Why Map

A List knows positions. A Map knows IDs.

Use a Map when one identifier belongs with one value — student ID, product ID, username, country code.

Collections

Collection is a group. Collections is the helper.

Collections is a utility class. It sorts, reverses, shuffles, and finds min and max.

List<Integer> numbers = new ArrayList<>();

numbers.add(20);

Collections.sort(numbers);

instanceof

Ask: is this object that type?

instanceof checks the actual type. From 1.5: a Dog is also an Animal.

Student student = new Student();
if (student instanceof Student) {
    System.out.println("This is a Student object.");
}

Animal animal = new Dog();
if (animal instanceof Dog) {
    System.out.println("This is a Dog.");
}
Use it when you have a parent-type variable and need to know the real child type before you act.

Read it as

Is animal a Dog? If yes, print. The check is true because we stored a Dog.
