Which logger

Your code calls SLF4J. Logback writes the line.

Facade

SLF4J

The Logger your classes call. Spring Boot uses this API.

Default

Logback

The implementation that writes the messages in a typical Spring Boot web app.

Alternative

Log4j2

Another implementation. It has its own dependency and its own configuration file.

This lesson stays with SLF4J and Logback. A Log4j2 project keeps its configuration separate from Logback.

Levels

A level says how serious the message is.

LevelMeaningExample
TRACEVery detailed informationDetailed method execution
DEBUGUseful during developmentChecking variable values
INFONormal application activitiesApplication started
WARNSomething needs attentionEmail is not verified
ERRORSomething went wrongDatabase connection failed

What you see

INFO hides DEBUG and TRACE.

  • TRACEDetailed method execution
  • DEBUGValidating student details
  • INFOCreating student
  • WARNStudent email is not verified
  • ERRORDatabase connection failed

Click a level. The application still records the quieter messages. This setting decides which ones appear.

Logger

One logger, four kinds of message.

StudentService
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

@Service
public class StudentService {

    private static final Logger logger =
            LoggerFactory.getLogger(StudentService.class);

    public void createStudent() {
        logger.info("Creating student");
        logger.debug("Validating student details");
        logger.warn("Student email is not verified");
        logger.error("Unable to save student");
    }
}

This method calls every level so the names are visible. In the student API, error is for a failed save.

The calls

LoggerFactory builds the logger. The level methods write.

Object

Logger

Generates the log messages for this class.

Factory

getLogger

LoggerFactory.getLogger creates that logger.

Normal

info

logger.info records an informational message.

Failure

error

logger.error records an error message.

debug is for development detail. warn is for something that needs attention. {} drops a value into the message: logger.info("Student created: {}", name).

application.properties

Spring Boot reads the logging settings from properties.

application.properties
# Set logging level
logging.level.root=INFO

# Enable debug logs for our application
logging.level.com.example.studentmanagement=DEBUG

# Save logs into a file
logging.file.name=logs/application.log

Three settings

Root sets the default. The package can be louder.

PropertyPurpose
logging.level.rootSets the default logging level.
logging.level.package-nameSets the level for one package.
logging.file.nameSaves logs into a file.

With root at INFO, DEBUG and TRACE from libraries stay off the screen. The package line turns DEBUG on for com.example.studentmanagement.

Format

The console pattern decides how that line looks.

application.properties
logging.pattern.console=%d{yyyy-MM-dd HH:mm:ss} %-5level %logger{36} - %msg%n

%d

Date

The date and time.

%-5level

Level

The level, padded to five letters.

%logger

Name

The logger name, shortened to 36 characters.

%msg

Message

The text you passed to the logger. %n starts the next line.
