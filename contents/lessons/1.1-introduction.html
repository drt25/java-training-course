Java download and setup

Install the JDK. Then set JAVA_HOME.

JAVA_HOME is the JDK folder — not the bin folder. Path must include bin so the terminal can find the tools.

1 Download Temurin or Oracle JDK 17 / 21 / 25 (Windows x64).
2 Run the installer.
3 Copy the JDK folder path. Do not copy bin.
4 System Properties → Environment Variables → New JAVA_HOME.
5 Edit Path → add %JAVA_HOME%\bin → close every terminal.
6 Check: java -version and javac -version.

Ubuntu lab

Same idea. One command installs the JDK.

sudo apt install openjdk-21-jdk 
java -version
javac -version

REM Windows: echo %JAVA_HOME%
REM Ubuntu:  echo $JAVA_HOME

JDK · JRE · JVM

What we install. What runs the code.

We install the JDK. Inside it is the JRE. Inside that is the JVM — the engine that runs bytecode.

JDK What we install. Has the compiler javac and other tools.
JRE What runs a finished program. Libraries plus the engine.
JVM The engine. Loads .class, checks it, then runs it.

Environment and Hello World

Save the file. Compile. Then run.

JAVA_HOME is the JDK folder. Path must include bin so the terminal can find the tools.

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Broadway!");
    }
}
1 Save as HelloWorld.java — same name as the class.
2 javac HelloWorld.java — this makes HelloWorld.class.
3 java HelloWorld — do not type .class.
