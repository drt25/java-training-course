POM

POM means Project Object Model.

pom.xml is Maven’s configuration file. These three names identify the project.

pom.xml
<project>
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example</groupId>
    <artifactId>mysql-maven-demo</artifactId>
    <version>1.0</version>
</project>

groupId

com.example

The organization or project group.

artifactId

mysql-maven-demo

The project name.

version

1.0

The application version.

Dependency

The same three names identify MySQL Connector/J.

A dependency is a library the project needs. This block replaces the manual JAR download.

        <artifactId>mysql-connector-j</artifactId>

Repository

Lifecycle

A build is a short sequence of steps.

compile, then test, then package. clean is separate: it deletes generated files.

1

compile

Compile src/main/java.

2

test

Compile and run tests.

3

package

Build the JAR.

Beside the chain

clean

Remove the target/ folder.

            <version>26.7.0</version>
        </dependency>
    </dependencies>
</project>

maven.compiler.release is the Java version Maven compiles for. This class uses 21.

Java code

Main.java only proves the connector is available.

JDBC stays in lesson 1.14. This class opens college and prints one line.

Main.java
package com.example;

import java.sql.Connection;
import java.sql.DriverManager;

public class Main {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/college";
        String username = "root";
        String password = "password";
        try {
            Connection connection =
                    DriverManager.getConnection(url, username, password);
            System.out.println("Database connected successfully!");
            connection.close();
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
