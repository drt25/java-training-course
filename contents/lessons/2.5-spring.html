Two classes

The service receives the repository.

StudentRepository
class StudentRepository {
    public void save() {
        System.out.println("Student saved");
    }
}
StudentService
class StudentService {
    private final StudentRepository repository;

    public StudentService(StudentRepository repository) {
        this.repository = repository;
    }

    public void registerStudent() {
        repository.save();
    }
}

The service does not write new StudentRepository().

Dependency injection

Spring passes the repository in.

Dependency injection means a class receives the object it needs. Spring creates both objects and connects them.

Spring Boot

Spring Boot starts a Spring application with less setup.

Spring Boot is built on Spring Framework. It supplies defaults and sets up common pieces for you.

Tools

Spring Framework

Objects, transactions, database access, and web support.

Start

Spring Boot

Defaults so a new project needs less setup.

  3. 3

  4. 4

This is a common shape. Other Spring applications can be arranged differently.
