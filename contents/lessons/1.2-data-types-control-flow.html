Data types

Class-based types

These are objects. The variable holds a reference, not the raw bits of an int.

String

Text. Name, phone, error message.

String name = "Ram";

Array

Fixed list of the same type.

int[] marks = {80, 70, 90};

Your class

A type you design. Many objects from one class.

Account a = new Account();

Big numbers

BigInteger and BigDecimal

Why not double for money

0.1 + 0.2 → 0.30000000000000004

Close, not exact. Banks cannot use this.

BigDecimal — exact decimal

new BigDecimal("1500.50")

Build from a String, not from a double.

BigInteger — whole numbers bigger than long: new BigInteger("10000000000"). Population, IDs, crypto-size counts.

Collections need objects

ArrayList stores objects, not int. Use ArrayList<Integer>.

Benefits

null for missing. Parse methods. Works with generics.

When

Primitive: local speed, never empty. Wrapper: lists, “no value”, form text.

Integer n = 5;      // autoboxing: int → Integer

Statements and blocks

Statement and block

A statement is one step. It ends with ;. Use it for one action.
A block is { }. Use it to group steps. A name made inside dies at }.
int pinTries = 0;     // statement
{
    int temp = 1;     // only inside this block
}
// temp cannot be used here

Conditional statements

if, else if, else

if — first test. else if — next test. else — leftover.

if (balance >= amount) {
    System.out.println("Sent");
} else if (frozen) {
    System.out.println("Wallet locked");
} else {
    System.out.println("Not enough balance");
}

Logical operators

&&   ||   !

&& both

Send only if not frozen and balance is enough. !frozen && balanceOk

|| either

Open the door if staff or manager. isStaff || isManager

! not

Flip true/false. !frozen means the wallet is free.

ATM login needs card and PIN. Do not write cardOk || pinOk — that lets one of them fail.

switch

Many fixed choices

Use switch when one value has many constant doors (1, 2, 3). Clearer than a long else if chain. One jump. Less nesting.
default runs when no case matches — the leftover door.

switch

break, and the modern form

// without break — fall through
switch (choice) {
    case 1:
        System.out.println("Deposit");
    case 2:
        System.out.println("Withdraw");
}
// choice 1 prints both lines
// modern — no fall through
switch (choice) {
    case 1 -> System.out.println("Deposit");
    case 2 -> System.out.println("Withdraw");
    default -> System.out.println("Invalid");
}

Old style: put break; after each case, or the next case also runs. Arrow -> does not fall through.

break, continue, return

Stop. Skip. Leave the method.

break — stop the loop

if (i == 5) break; in a 1..10 loop prints 1 2 3 4.

continue — skip this round

if (i == 3) continue; in 1..5 prints 1 2 4 5. Loop does not stop.

return — exit the method

if (age < 18) return; leaves checkAge at once.

for (int i = 1; i <= 10; i++) {
    if (i == 5) break;
    System.out.println(i);
}
1 2 3 4
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    System.out.println(i);
}
1 2 4 5

enum

A closed list of names

An enum is a fixed set. The compiler rejects a typo like "depoist".
Names: UPPER_SNAKE — DEPOSIT, PENDING.
Use for choices that rarely change (status, txn type, role). Do not use for names that grow every day (customer names).
enum TxnType { DEPOSIT, WITHDRAW, TRANSFER }

TxnType t = TxnType.DEPOSIT;
// also: PENDING, PAID, FAILED

Type conversion

Widening, narrowing, and text

Widening

Bigger box. Automatic. Mix int into long.

long n = 25;

Narrowing

Smaller box. You cast. Bits can vanish.

int x = (int) 3.9; // 3 
int n = Integer.parseInt("25");
long value = Long.parseLong("100000");
double price = Double.parseDouble("99.99");
boolean active = Boolean.parseBoolean("true");
