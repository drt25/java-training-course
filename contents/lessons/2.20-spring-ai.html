The key

The API key stays in an environment variable.

application.properties
server.port=8084
spring.ai.openai.api-key=${OPENAI_API_KEY}

Set OPENAI_API_KEY in the environment before you run the app. An OpenAI API account and its billing are separate from a ChatGPT subscription.

The prompt

The system line is the instruction. The user line is the sentence.

GrammarService.java
public GrammarService(ChatClient.Builder builder) {
    this.chatClient = builder.build();
}

public String correctGrammar(String sentence) {
    return chatClient.prompt()
            .system("Correct the grammar of the given sentence. "
                    + "Return only the corrected sentence.")
            .user(sentence)
            .call()
            .content();
}

A prompt is the text sent to the model. system tells it the job. user is the sentence to correct.

The endpoint

POST the sentence. Return the model’s text.

GrammarController.java
@RestController
@RequestMapping("/api/grammar")
public class GrammarController {

    @PostMapping("/correct")
    public String correct(@RequestBody String sentence) {
        return grammarService.correctGrammar(sentence);
    }
}

content() is the corrected sentence the service already received from OpenAI.

Words

Six words cover this call.

WordMeaning
AI modelThe program that reads the input and writes a response.
PromptThe instruction and the sentence sent to the model.
OpenAI APIThe web address Spring Boot calls to reach the model.
API keyThe secret that proves this application may call that address.
TokenA small piece of text. The API bills those pieces.
Spring AIThe Spring library that builds the ChatClient for you.
