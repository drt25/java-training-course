Constructor

Same name as the class. Runs when you new.

Without a constructor, numbers start at 0 and names start empty. The constructor sets the first values.

Name

Must match the class: Account.

No return type

Not void. Not int.

When

Java calls it on new Account(...).

Constructor

Pass the starting name and balance

Account ram = new Account("Ram", 15000);
Account hari = new Account("Hari", 8000);

One line each

No more ram.name = after new. The constructor does that job.

Encapsulation

Keep the wallet in the pocket

If balance is public, anyone can write ram.balance = -500. A real bank would not allow that.

Open field

ram.balance = -500; — broken wallet.

Private field

Use deposit, withdraw, getBalance. The object checks the rules.

Encapsulation

private data. public actions.

private int balance;

public int getBalance() {
    return balance;
}

public void deposit(int amount) {
    if (amount > 0) {
        balance += amount;
    }
}

One getter is enough

Read the balance. Do not give the world a setBalance that skips the rules.

Lab: ConstructorEncaps.java

this

this.name is the field. name is the parameter.

When both have the same name, Java uses the nearest one. this points at this object.

public Account(String name, int balance) {
    this.name = name;
    this.balance = balance;
}

Without this

name = name; copies the parameter onto itself. The field stays empty.

this

this() calls another constructor

Name only today. Do not drill chaining. One extra use of the same word.

public Account(String name) {
    this(name, 0);
}

Read it as

Start this account with a name. Balance starts at 0. Reuse the other constructor.

Static

One value shared by every account

1.3b said static means call it like main. Today: it belongs to the class, not to Ram or Hari.

Each object

name and balance — Ram and Hari each have their own.

The class

accountCount — one number for the bank.

Call it on the class

Account.accountCount — not ram.accountCount.

Static

Count how many accounts you built

static int accountCount = 0;

Account() {
    accountCount++;
}

System.out.println(Account.accountCount);

Shared

Two new Account() calls. Count is 2. Both objects see the same number.

Lab: StaticUses.java

Static block

Runs once when the class loads

Not a constructor. A constructor runs for every object. A static block runs one time, before you use the class.

static {
    System.out.println("Bank ready");
}

Use it for

One-time setup. A starting message. A default rate. Then main runs.
