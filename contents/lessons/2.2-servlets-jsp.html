First servlet

This class answers /hello.

HelloServlet.java
import java.io.IOException;
import java.io.PrintWriter;
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

@WebServlet("/hello")
public class HelloServlet extends HttpServlet {

    @Override
    protected void doGet(HttpServletRequest request,
                         HttpServletResponse response)
            throws ServletException, IOException {

        response.setContentType("text/html");

        PrintWriter out = response.getWriter();
        out.println("<h1>Hello, Students!</h1>");
    }
}
/StudentApp/hello

Hello, Students!

A GET request to that address runs doGet. jakarta.servlet runs on Tomcat 10 or newer.

Methods

Five methods do the work.

init()

Runs when the servlet is initialized.

service()

Receives the request and calls the HTTP method.

doGet()

Handles a GET request.

doPost()

Handles a POST request.

destroy()

Runs before the servlet is taken out of service.

Lifecycle

Tomcat calls these methods in order.

init() runs once. Request handling runs again and again. destroy() runs when Tomcat removes the servlet.

  1. 1

    Loaded and created

    Tomcat loads the class and makes one servlet object.

  2. 2

    init()

    Initialization. Normally once for that object.

  3. 3

    service()

    Each request. service() calls doGet() or doPost().

  4. 4

    destroy()

    Cleanup when the container removes the servlet.

Parameters

The servlet reads the name and answers.

doPost
@WebServlet("/register")
public class StudentServlet extends HttpServlet {

    @Override
    protected void doPost(HttpServletRequest request,
                          HttpServletResponse response)
            throws IOException {

        String name = request.getParameter("studentName");

        response.setContentType("text/html");
        response.getWriter().println("Welcome, " + name);
    }
}

Forward

Forward stays on this same request.

The server passes the work to another page. The browser does not make a new request.

RequestDispatcher
request.setAttribute("name", name);

request.getRequestDispatcher("/welcome.jsp")
       .forward(request, response);
The name stays on the request, so welcome.jsp can read it.

Redirect

Redirect tells the browser to ask again.

The server sends a new address. The browser then makes a new request to that address.

sendRedirect
response.sendRedirect("login.jsp");
A forward uses the request already in progress. A redirect starts a new request.

JSP

JSP is the page that shows the result.

JavaServer Pages runs on the server and builds HTML. The servlet processes the name. The JSP page presents it.

<html>

</head>

    <h1>Welcome, ${name}!</h1>
</body>
</html>
