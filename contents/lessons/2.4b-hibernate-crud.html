Every write

Six steps, every time we change data.

1

Open

openSession()

2

Begin

beginTransaction()

3

Work

Persist, change, or remove.

4

Commit

The database keeps the change.

5

Roll back

On failure, undo this transaction.

6

Close

session.close() in finally.

Insert

persist() saves a new student.

InsertStudent.java
SessionFactory sessionFactory = HibernateUtil.getSessionFactory();
Session session = sessionFactory.openSession();
Transaction transaction = null;
try {
    transaction = session.beginTransaction();
    Student student = new Student();
    student.setName("Ram");
    student.setEmail("ram@example.com");
    session.persist(student);
    transaction.commit();
    System.out.println("Saved student " + student.getId());
} catch (Exception exception) {
    if (transaction != null) {
        transaction.rollback();
    }
} finally {
    session.close();
}

The lab does not call setId. The next slide lets MySQL assign the id. The printed number is the new primary key.

Generated id

@GeneratedValue assigns the primary key.

Student.java
@Id
@GeneratedValue(strategy = GenerationType.IDENTITY)
private int id;

MySQL fills id when the row is inserted. After commit(), student.getId() has that number.

Get by id

find() loads one student.

FindStudent.java
SessionFactory sessionFactory = HibernateUtil.getSessionFactory();
Session session = sessionFactory.openSession();
Transaction transaction = null;
try {
    transaction = session.beginTransaction();
    Student student = session.find(Student.class, 1);
    if (student == null) {
        System.out.println("No student with id 1");
    } else {
        System.out.println(student.getName());
        System.out.println(student.getEmail());
    }
    transaction.commit();
} catch (Exception exception) {
    if (transaction != null) {
        transaction.rollback();
    }
} finally {
    session.close();
}

A missing id returns null. Use the id printed by InsertStudent.

Update

Change the object, then commit.

The student loaded inside the transaction is managed. Hibernate writes the new email. There is no separate update call.

UpdateStudent.java
SessionFactory sessionFactory = HibernateUtil.getSessionFactory();
Session session = sessionFactory.openSession();
Transaction transaction = null;
try {
    transaction = session.beginTransaction();
    Student student = session.find(Student.class, 1);
    student.setEmail("ram@school.com");
    transaction.commit();
} catch (Exception exception) {
    if (transaction != null) {
        transaction.rollback();
    }
} finally {
    session.close();
}

Delete

remove() deletes that student.

DeleteStudent.java
SessionFactory sessionFactory = HibernateUtil.getSessionFactory();
Session session = sessionFactory.openSession();
Transaction transaction = null;
try {
    transaction = session.beginTransaction();
    Student student = session.find(Student.class, 1);
    if (student != null) {
        session.remove(student);
    }
    transaction.commit();
} catch (Exception exception) {
    if (transaction != null) {
        transaction.rollback();
    }
} finally {
    session.close();
}

HQL

HQL names the class. SQL names the table.

SQL
SELECT id, name, email
FROM students;
HQL
FROM Student

Student is the Java class. students is the MySQL table.

List

FROM Student returns every student.

ListStudents.java
SessionFactory sessionFactory = HibernateUtil.getSessionFactory();
Session session = sessionFactory.openSession();
Transaction transaction = null;
try {
    transaction = session.beginTransaction();
    List<Student> students = session
            .createQuery("FROM Student", Student.class)
            .getResultList();
    for (Student student : students) {
        System.out.println(student);
    }
    transaction.commit();
} catch (Exception exception) {
    if (transaction != null) {
        transaction.rollback();
    }
} finally {
    session.close();
}

Search

:name holds the value we are looking for.

SearchStudent.java
SessionFactory sessionFactory = HibernateUtil.getSessionFactory();
Session session = sessionFactory.openSession();
Transaction transaction = null;
try {
    transaction = session.beginTransaction();
    List<Student> students = session.createQuery(
            "FROM Student WHERE name = :name",
            Student.class)
            .setParameter("name", "Ram")
            .getResultList();
    for (Student student : students) {
        System.out.println(student);
    }
    transaction.commit();
} catch (Exception exception) {
    if (transaction != null) {
        transaction.rollback();
    }
} finally {
    session.close();
}
