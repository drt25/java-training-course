Hibernate

Hibernate saves a Java object for us.

Lesson 1.14 wrote the SQL. Today the program hands Hibernate a Student, and Hibernate writes the row.

Hibernate is an ORM tool. It maps a Java class to a database table and runs the SQL for ordinary saves, loads, changes, and deletes.

ORM

A Student object is a row in students.

ORM means Object-Relational Mapping. The class is the table. The fields are the columns. One object is one row.

Student.java
class Student {
    int id;
    String name;
    String email;
}

JDBC and Hibernate

The same insert, two ways.

JDBC
Connection con = DriverManager.getConnection(url, user, password);
PreparedStatement ps = con.prepareStatement(
        "INSERT INTO students (name, email) VALUES (?, ?)");
ps.setString(1, "Ram");
ps.setString(2, "ram@example.com");
ps.executeUpdate();
Hibernate
Student student = new Student();
student.setName("Ram");
student.setEmail("ram@example.com");

session.persist(student);

Hibernate still uses JDBC underneath. The program stops writing that SQL by hand.

    Does the database work.

  5. 5

    Transaction

    Commits or rolls back a write.

  6. 6

    hibernate_demo

    The MySQL database for this lesson.

A read can run on a session alone. A write uses a transaction.

Pieces

Each piece has one job.

Reads the file

SessionFactory

Built once

Shared by the whole program.

Session

Does the work

Persist, find, change, remove.

Transaction

Commit or roll back

A failed write leaves the database as it was.

Entity

Annotations tell Hibernate this class is a table.

Student.java
@Entity
@Table(name = "students")
public class Student {
    @Id
    private int id;
    private String name;
    private String email;
}

@Entity

Persistent class

Hibernate stores objects of this class.

@Table

students

The table name in MySQL.

@Id

Primary key

id identifies one row.

@GeneratedValue lets the database assign id. The next lesson turns that on.

hibernate.cfg.xml

The file holds the database setup.

hibernate.cfg.xml
<property name="hibernate.connection.url">
    jdbc:mysql://localhost:3306/hibernate_demo
</property>
<property name="hibernate.connection.username">root</property>
<property name="hibernate.connection.password">password</property>
<property name="hibernate.dialect">org.hibernate.dialect.MySQLDialect</property>
<property name="hibernate.show_sql">true</property>
<property name="hibernate.hbm2ddl.auto">update</property>
<mapping class="com.example.Student"/>

update creates a missing table and keeps rows that are already there. show_sql prints the SQL Hibernate runs.

SessionFactory

Build the factory once.

HibernateUtil.java
Configuration configuration = new Configuration();
configuration.configure();
sessionFactory = configuration.buildSessionFactory();

configure() reads hibernate.cfg.xml. Every later class asks this factory for a session.

Check
