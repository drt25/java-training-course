What to install

Five pieces run the student API.

PiecePurpose
UbuntuThe operating system.
Java 21Runs the Spring Boot JAR.
MySQLStores the students.
JARThe packaged student API.
FirewallDecides which ports can be reached.

Prepare

Update Ubuntu, then install Java, MySQL, and a database user.

Packages
sudo apt update
sudo apt install -y openjdk-21-jre-headless mysql-server
MySQL
CREATE DATABASE student_db;
CREATE USER 'student_user'@'localhost'
  IDENTIFIED BY 'choose-a-password';
GRANT ALL ON student_db.*
  TO 'student_user'@'localhost';

Run these after ssh ubuntu@SERVER_IP. Leave port 3306 closed to the internet. MySQL answers only on that server.

The file

A JAR is the packaged application.

One file holds the student API and the libraries it needs.
coding/2.14/student-api
mvn clean package

Maven writes target/student-api-1.0.jar. Build with mvn.

Ship and run

Copy the JAR, then start it with Java.

Upload
scp target/student-api-1.0.jar \
  ubuntu@SERVER_IP:/home/ubuntu/
Run
java -jar student-api-1.0.jar

DB_PASSWORD=choose-a-password \
  nohup java -jar student-api-1.0.jar \
  > app.log 2>&1 &

The console is the log. A plain java -jar stops when the SSH session closes. The nohup line keeps it running and writes the log to app.log.

Same server

Spring Boot talks to MySQL on localhost.

application.properties
spring.datasource.url=jdbc:mysql://localhost:3306/student_db
spring.datasource.username=student_user
spring.datasource.password=${DB_PASSWORD}
server.port=8080

The classroom project keeps root, password, and port 8081. On the server, the password comes from the DB_PASSWORD environment variable. Leave port 3306 closed to the internet.

The public address

An IP finds the server. A port finds the API.

WordMeaning
IP addressIdentifies the server.
PortIdentifies the program. The API uses 8080.
FirewallAllows or blocks a port. The API needs port 8080 open.
HTTPThe protocol the browser and Postman use.
HTTPSHTTP with a TLS certificate.
DomainA readable name, such as api.example.com.
DNSPoints that name at the public IP.

http://SERVER_PUBLIC_IP:8080/api/students
https://api.example.com/api/students
sudo ufw allow 8080
If you enable the firewall, allow SSH as well. A TLS certificate turns the address into HTTPS.
